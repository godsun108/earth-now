# ATLAS

ATLAS is EARTH NOW's shared planetary observation model.

Every datum declares what it is, where and when it applies, its provenance, retrieval time, and semantic class.

## Semantic classes
- observed — source/sensor/catalog observation
- calculated — deterministic derivation
- forecast — model prediction, never presented as observation
- camera — verified visual endpoint/status
- visualization_anchor — display-only location, never physical geography

Rule: provenance and semantics travel with every observation. If the system cannot truthfully describe what a datum represents, it must not glow.
